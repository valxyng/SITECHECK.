# SITECHECK

Сервис пассивного аудита публично доступных сайтов: SEO, HTML, изображения, базовая доступность и технические заголовки.

## Деплой на Vercel

1. Загрузите репозиторий на GitHub.
2. Откройте [Vercel](https://vercel.com/new), войдите через GitHub и выберите репозиторий `sitecheck`.
3. Vercel автоматически определит Next.js. Оставьте стандартные Build Command (`next build`) и Output Directory пустым.
4. В **Environment Variables** добавьте `NEXT_PUBLIC_TELEGRAM_URL` со ссылкой на ваш Telegram, если используете кнопку связи.
5. Нажмите **Deploy**. Каждый последующий push в ветку `main` будет автоматически публиковать новую версию.

## Важное ограничение MVP

После проверки отчёт сохраняется в текущей сессии браузера. Это делает проверку совместимой с serverless-развёртыванием Vercel, но ссылка на индивидуальный отчёт не является постоянной. Для истории отчётов и общих ссылок подключите PostgreSQL, Vercel KV или Upstash Redis.
